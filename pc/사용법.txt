번호판 자동정리 (PC용) 사용법
================================

하는 일
  지정한 "감시 폴더"(하위 폴더 포함)에 새 사진이 생기면
  1) 번호판을 읽고
  2) 파일 이름을 "년월일시분초_번호" 로 바꾼 뒤   예) 20261123083700_67너7570.jpg
  3) "백업 폴더" 안의 같은 하위 폴더 위치로 옮깁니다.
     예) 감시폴더\1층\A구역\IMG_001.jpg  →  백업폴더\1층\A구역\20261123083700_67너7570.jpg
  인터넷 연결 없이 이 PC 안에서만 동작합니다.

처음 실행
  1. 받은 PlateWatcher-win64.zip 을 원하는 곳(예: C:\번호판자동정리)에 압축 풉니다.
  2. 번호판자동정리\PlateWatcher\PlateWatcher.exe 를 더블클릭합니다.
     - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누르세요.
       (서명하지 않은 프로그램이라 처음 한 번 뜨는 경고입니다.)
  3. [찾아보기]로 감시할 폴더와 백업 폴더를 고릅니다.
     백업 폴더는 감시 폴더 밖에 있어야 합니다.
  4. [감시 시작]을 누르면 끝. 창을 최소화해 두면 계속 동작합니다.
     폴더 설정은 저장되어 다음에 켤 때 그대로 남아 있습니다.

옵션
  - 사진 촬영시각 사용: 사진 안에 기록된 촬영시각(EXIF)을 이름에 씁니다.
    촬영시각이 없는 사진은 파일이 만들어진 시각을 씁니다.
    끄면 항상 파일이 만들어진 시각을 씁니다.
  - 시간과 번호 사이에 _ 넣기: 끄면 2026112308370067너7570.jpg 처럼 붙여 씁니다.
  - 번호를 못 읽은 사진도 원래 이름으로 백업에 옮기기: 켜져 있으면(기본) 원래 이름 그대로
    백업 폴더로 옮기고, 끄면 감시 폴더에 그대로 둡니다.
  - 시작할 때 이미 있던 사진도 처리: 기본은 꺼짐(감시 시작 후 새로 생긴 사진만 처리).
  - 프로그램을 켜면 바로 감시 시작 / 윈도우 켤 때 자동 실행: 두 개를 같이 켜 두면
    PC를 켜기만 해도 알아서 감시합니다.

알아두면 좋은 것
  - 같은 이름이 이미 있으면 뒤에 _2, _3 을 붙입니다 (덮어쓰지 않음).
  - 차가 여러 대 찍힌 사진은 가장 크게 찍힌 차의 번호를 씁니다.
  - 복사 중인 파일은 다 써질 때까지 기다렸다가 처리합니다 (2초마다 확인).
  - 처리 내역은 백업 폴더의 "처리기록.csv" 에 쌓입니다 (엑셀로 열림).
  - 대상 파일: jpg, jpeg, png, bmp, webp, tif
  - 번호판 인식은 아직 개선 중입니다. 틀린 번호가 보이면 사진을 보내 주세요.
